# Build without local Xcode and install with KSign

You do **not** need Xcode on your own computer if you use the GitHub Actions IPA build. The workflow builds NeuraL on GitHub's macOS runner, uploads an unsigned IPA, and you can sign that IPA with your own certificate in KSign.

## What you need

- A GitHub account with access to run this repo's Actions workflow.
- Your signing certificate and provisioning profile already set up in KSign.
- Your DeepSeek/Qwen `.gguf` saved somewhere you can later copy to the iPhone Files app.

## 1. Build the unsigned IPA in GitHub Actions

1. Open the repo on GitHub.
2. Go to **Actions**.
3. Select **Build NeuraL IPA**.
4. Click **Run workflow**.
5. Pick the branch containing these changes. If you cannot find it, push the local commits first with `git push origin HEAD:codex/build-dreamstate-local-cognition-layer`.
6. Wait for the job to finish.
7. Download the `NeuraL-unsigned` artifact.
8. Unzip the artifact if GitHub downloaded it as a `.zip`; inside is `NeuraL-unsigned.ipa`.

The workflow intentionally builds with code signing disabled, then packages `NeuraL.app` into `NeuraL-unsigned.ipa` for external signing.

## 2. Sign with KSign

1. Open KSign.
2. Import or select your certificate and provisioning profile.
3. Import `NeuraL-unsigned.ipa`.
4. Sign the IPA.
5. Install the signed IPA to your phone using your normal KSign/install flow.

Use an app identifier/provisioning profile that matches the bundle ID generated by the project (`com.neural.NeuraL` unless you intentionally changed the XcodeGen bundle settings).

## 3. Put your GGUF on the phone

After the signed app is installed:

1. AirDrop, iCloud Drive, Finder, or another Files provider can place the `.gguf` on the phone.
2. Keep the filename ending in `.gguf`.
3. Open **NeuraL** → **Models** → **Load GGUF Model**.
4. Pick the DeepSeek/Qwen GGUF.
5. Wait for model status, then go to **Chat**.

## Troubleshooting KSign installs

| Problem | Fix |
| --- | --- |
| KSign rejects the IPA | Make sure you selected `NeuraL-unsigned.ipa`, not the GitHub artifact `.zip`. |
| Install fails due to bundle/profile mismatch | Use a provisioning profile whose app ID matches the app bundle ID, or rebuild with the bundle ID you need. |
| App opens but no model is loaded | Copy the GGUF into Files and load it from the Models tab; the IPA does not include your model. |
| The GGUF is too big for iCloud/AirDrop | Copy through Finder or another local Files provider, or use a smaller quantization. |
