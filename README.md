## Using your own GGUF on iPhone

If you already have a DeepSeek-distilled Qwen GGUF or another quantized text-generation GGUF, see [Use a local GGUF model on iPhone](PHONE_GGUF_GUIDE.md). The short version is: install NeuraL on the phone, save the `.gguf` in Files/iCloud/On My iPhone, open **Models**, tap **Load GGUF Model**, pick the file, wait for model status, then chat locally.

If you do not want to use Xcode locally and plan to sign with KSign, use the [no-Xcode KSign workflow](NO_XCODE_KSIGN_GUIDE.md).
